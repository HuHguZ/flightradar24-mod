Неофициальная сборка Flightradar24 11.15.1: включён тир Business, убрана реклама, обойдён вход, открыты данные о бортах и метео-радар.

### Исправлено в этой сборке

Серийный номер (MSN) и возраст борта раньше оставались `N/A`: заполнение шло в модель, которую экран борта не читает, а собственный его модели поля никто не трогал. Теперь значения подставляются на уровне геттеров панели борта, поэтому MSN, дата выпуска и возраст показываются для любого борта, который есть в локальной базе.

### Файлы

- **Flightradar24_11.15.1_Business_arm64.apk** — рекомендуемый: один обычный APK, ставится напрямую.
- **Flightradar24_11.15.1_Business_unlocked.xapk** — то же самое в виде XAPK (база + сплиты), если удобнее ставить через XAPK Installer или APKPure.

Сборка только для arm64 (в исходном пакете других ABI нет).

### Установка

1. Удалите официальное приложение `com.flightradar24free` — подпись другая, поверх не встанет.
2. Установите APK и запустите.
3. На первом запуске приложение покажет окно согласия на обработку данных — нажмите «Accept all».

Аккаунт не нужен, рекламы нет, платные функции включены по умолчанию.

### Что внутри

- тир `Business`, все фичи-флаги включены, лимиты 999
- баннеры и интерстишлы не создаются вообще
- серийный номер, возраст, страна регистрации, расширенные Mode S, squawk, FIR — из открытых данных, база лежит внутри APK
- метео-слои и радар осадков работают; при отсутствии креденшелов радар уходит на публичные тайлы RainViewer

### Ограничения

- закладки и алерты остаются серверными, для них нужен аккаунт
- ключ карты публичный, квота у него общая — при исчерпании карта посереет
- подпись не Play-овская: нет автообновления через Play и не работают `https://`-ссылки
